# Atlas Compass website

Official landing page for Flag Quiz: Atlas Compass, hosted with Cloudflare Pages Direct Upload at https://atlascompass.get.ng/.

The root `app-ads.txt` is required for AdMob app verification. Keep its publisher ID synchronized with the owner's AdMob account. The public website privacy page is `/privacy/`. Older released app builds still link to the prior privacy-policy URL until an app update changes that link.

The screenshots and icon are derived from the Atlas Compass app's store assets. Deployment is a direct upload of the static files; no repository integration is configured in Cloudflare Pages.
